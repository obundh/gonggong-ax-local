# Threads 게시글 초안

공공AX 로컬 시리즈 5, 문서 리소스 추출기 📦

HWPX·DOCX·PPTX·XLSX·ODF·Visio·XPS·EPUB 같은 ZIP 패키지 문서 33종을 넣으면
이미지·영상·오디오·첨부·글꼴·서식·문서 구조를 자동으로 분류합니다.

초보자 실행 순서도 5장으로 정리했습니다.

1. GitHub `Releases` 열기
2. `series5-v0.1.0`의 `Assets`에서 실행용 ZIP 받기
3. `Source code (zip)` 말고 Windows용 ZIP 선택
4. `모두 압축 풀기`
5. `시리즈5_실행.cmd` 더블클릭

필요한 파일만 저장하거나 전체를 분류 폴더 ZIP으로 저장할 수 있습니다. 문서는 로컬
브라우저 메모리에서 처리하고 원본은 바꾸지 않습니다. 매크로는 실행하지 않고 별도
리소스로만 분류합니다.

한 파일 최대 100 MB. HWP·DOC·PPT·XLS·PDF·일반 ZIP·암호·DRM·손상 문서는
지원하지 않습니다.
