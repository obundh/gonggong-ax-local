# 시리즈 5 만화 한국어 대체텍스트

SNS에서 이미지별 대체텍스트를 입력할 때는 `짧은 대체텍스트`를 사용합니다. 이미지
내용을 글로도 제공해야 하는 게시물이나 웹페이지에는 `상세 설명`을 함께 연결합니다.

## 1장

파일: `series5-comic-01.png`

짧은 대체텍스트:

> 빨간 스카프를 한 검은 고양이가 노트북 속 ZIP 상자에서 이미지·영상·오디오·첨부·글꼴·XML 리소스가 나오는 모습을 가리킨다. 오른쪽에는 문서 선택, 리소스 분류, 전체 저장의 3단계가 표시된다.

상세 설명:

상단 제목은 `문서 리소스 추출기`, 보조 문구는 `ZIP 패키지 문서 33종`이다.
노트북 앞 ZIP 상자에서 이미지, 영상, 오디오, 첨부, 글꼴, XML 아이콘이 분리되어
나온다. 아래에는 HWPX, DOCX, PPTX, XLSX, ODF, EPUB 예시 파일이 놓여 있다.
오른쪽에는 1 문서 선택, 2 리소스 분류, 3 전체 저장 순서가 있고, 하단 문구는
`확장자 변경 없이 바로!`이다.

## 2장

파일: `series5-comic-02.png`

짧은 대체텍스트:

> 고양이가 GitHub Releases 화면의 series5-v0.1.0 Assets에서 Windows 실행용 ZIP을 선택하는 경로를 가리킨다. Source code zip은 받지 말라는 표시가 있다.

상세 설명:

상단 제목은 `GitHub에서 ZIP 받기!`이다. 왼쪽에 1 Releases, 2 series5-v0.1.0,
3 Assets, 4 Series 5 포터블 ZIP의 네 단계가 세로로 이어진다. 가운데의 예시 릴리스
화면은 `series5-v0.1.0`과 Assets를 보여 준다. 고양이는 초록색 다운로드 화살표를
들고 실행용 ZIP을 가리킨다. 하단에는 `Source code 말고 ZIP! 공식 Releases에서만
받기`라고 적혀 있다.

## 3장

파일: `series5-comic-03.png`

짧은 대체텍스트:

> 실행용 ZIP을 모두 압축 푼 뒤 같은 폴더의 시리즈5_실행.cmd를 더블클릭해 시리즈 5 전용 창을 여는 네 단계를 보여 준다. ZIP 안에서 바로 실행하면 안 된다는 경고도 있다.

상세 설명:

상단 제목은 `압축 풀고, 딸깍 실행!`이다. 1 모두 압축 풀기, 2
`시리즈5_실행.cmd` 찾기, 3 더블클릭, 4 Series 5 전용 창 열림 순서가 표시된다.
가운데 고양이가 압축 상자에서 실행 파일을 꺼내 가리킨다. 왼쪽 아래에는 ZIP 안에서
바로 실행하는 모습에 빨간 X가 있다. 아래에는 `Node.js 설치 없음`, `설치 없이 실행`,
`공식 ZIP만 실행` 안내가 있다.

## 4장

파일: `series5-comic-04.png`

짧은 대체텍스트:

> 문서를 선택하거나 끌어놓으면 이미지·영상·오디오·첨부·글꼴·서식·스크립트·매크로·문서 구조·기타로 자동 분류되고, 카드와 미리보기에서 정보를 확인하는 과정을 보여 준다.

상세 설명:

상단 제목은 `문서 넣고 자동 분류!`이다. 1 파일 선택 또는 끌어놓기, 2 자동
분석·추출, 3 분류·미리보기의 흐름이 표시된다. 큰 모니터에는 왼쪽 분류 목록, 가운데
리소스 카드, 오른쪽 이미지 미리보기와 파일명·경로·크기·해상도·형식·색상 모드·사용
위치가 보인다. 화면 속 개수와 파일명은 예시다. 하단에는 분류 항목과 `최대 100 MB`,
`고르면 바로 시작! 원본은 그대로!` 안내가 있다.

## 5장

파일: `series5-comic-05.png`

짧은 대체텍스트:

> 리소스 카드를 골라 개별 파일로 저장하거나 이미지·첨부파일·오디오·글꼴·문서구조 폴더가 든 전체 ZIP으로 저장하는 방법과 로컬 처리·원본 보존·매크로 미실행 원칙을 보여 준다.

상세 설명:

상단 제목은 `필요한 리소스 저장!`이다. 왼쪽에 1 카드 선택, 2 파일 저장,
3 분류 폴더로 구성된 전체 ZIP 저장이 이어진다. 오른쪽 방패에는 `브라우저 메모리
처리`, `외부 전송 없음`, `원본 변경 없음`, `매크로 실행 안 함`, `암호·DRM·손상
미지원`이 표시된다. 매크로 문서와 자물쇠 그림 옆에도 `매크로 실행 안 함`이 적혀
있다. 하단 고양이의 말풍선은 `추출은 자동, 사용은 사람 확인!`이다.
