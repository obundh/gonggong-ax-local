# 시리즈 5 만화 재생성 프롬프트 사양

이 문서는 5장의 시각적 의도와 문구를 재현하기 위한 최종 프롬프트 사양입니다.
동일한 프롬프트를 다시 사용해도 생성 모델의 특성상 선, 글자, 배치가 완전히 같아지지는
않습니다. 생성 결과의 한글, 파일명, 지원 범위, 안전 문구는 사람이 반드시 교정합니다.

## 공통 사양

모든 장에 다음 지시를 공통으로 적용합니다.

```text
한국어 초보자용 소프트웨어 안내 만화 한 장. 따뜻한 아이보리 종이 배경, 손으로 그린
잉크선과 옅은 수채화 질감, 둥글고 친근한 교육용 인포그래픽. 검은색과 흰색 털,
큰 황금색 눈, 빨간 스카프를 한 활기찬 고양이 안내 캐릭터를 동일하게 유지한다.
굵고 읽기 쉬운 검은색 한글 제목, 핵심 단어만 짙은 빨간색, 단계 번호는 빨간 원,
성공 표시는 녹색, 경고는 빨간 X. 검은색 둥근 테두리의 단계 카드, 점선 화살표,
큰 마우스 커서, 단순한 Windows 창과 파일·폴더 아이콘을 사용한다. 한 장만 봐도
위에서 아래 또는 왼쪽에서 오른쪽으로 순서를 이해할 수 있게 한다. 정사각형 최종
캔버스용 중앙 안전 영역을 확보한다. 외부 회사·기관의 공식 로고, 워터마크,
광고 표식은 넣지 않는다. 실제 제품의 인증이나 보증을 암시하지 않는다.
```

공통 금지 요소:

```text
사진풍, 3D 렌더, 작은 본문, 복잡한 배경, 공포 표현, 실제 개인정보, 외부 브랜드
로고, 공식 인증 배지, 원격 서버 업로드 장면, 매크로 실행 장면, 원본 문서가 변경되는
장면을 넣지 않는다.
```

## 1장 프롬프트

```text
공통 사양을 적용한다. 상단 왼쪽에 1/5, 큰 제목은 "문서 리소스 추출기", 빨간
캡슐 문구는 "ZIP 패키지 문서 33종". 중앙에는 노트북과 열린 ZIP 상자, 상자에서
이미지·영상·오디오·첨부·글꼴·XML을 뜻하는 여섯 아이콘이 점선 화살표를 따라
나오게 한다. 고양이는 노트북과 아이콘을 신나게 가리킨다. 아래에는 HWPX, DOCX,
PPTX, XLSX, ODF, EPUB 예시 문서 카드를 놓는다. 오른쪽 세로 단계 카드는
"1 문서 선택", "2 리소스 분류", "3 전체 저장". 하단 말풍선은
"확장자 변경 없이 바로!". ZIP을 직접 확장자 변경해야 한다는 인상을 주지 않는다.
```

## 2장 프롬프트

```text
공통 사양을 적용한다. 상단 왼쪽에 2/5, 큰 제목은 "GitHub에서 ZIP 받기!".
초보자가 GitHub 릴리스에서 실행용 파일을 찾는 흐름을 그린다. 왼쪽 네 단계는
"1 Releases", "2 series5-v0.1.0", "3 Assets", "4 Series 5 포터블 ZIP".
중앙에는 실제 스크린샷이 아닌 단순화한 릴리스 페이지를 그리고 series5-v0.1.0,
Assets, Windows 10/11 x64용 다운로드 항목을 보여 준다. GitHub 서비스명은 안내
텍스트로만 사용하고 공식 로고는 넣지 않는다. 자동 생성 "Source code (zip)"에는
빨간 X를 표시한다. 고양이는 큰 녹색 아래 화살표를 들고 실행용 ZIP을 가리킨다.
하단 말풍선은 "Source code 말고 ZIP! 공식 Releases에서만 받기".
```

## 3장 프롬프트

```text
공통 사양을 적용한다. 상단 왼쪽에 3/5, 큰 제목은 "압축 풀고, 딸깍 실행!".
상단 네 단계는 "1 모두 압축 풀기", "2 시리즈5_실행.cmd", "3 더블클릭",
"4 Series 5 전용 창 열림". 고양이가 ZIP 상자에서 시리즈5_실행.cmd 파일을
꺼내 가리키고, 화살표가 어두운 녹색 S5 시작 화면으로 이어지게 한다. 왼쪽 아래에는
ZIP 안의 파일을 바로 실행하는 장면에 빨간 X와 "압축 안에서 실행 X"를 표시한다.
하단 확인 표시는 "Node.js 설치 없음", "설치 없이 실행", "공식 ZIP만 실행".
```

## 4장 프롬프트

```text
공통 사양을 적용한다. 상단 왼쪽에 4/5, 큰 제목은 "문서 넣고 자동 분류!".
상단 세 단계는 "1 파일 선택 또는 파일 끌어놓기", "2 자동 분석·추출",
"3 분류·미리보기". 중앙 모니터에 세 칸 앱 화면을 그린다. 왼쪽에는 이미지, 영상,
오디오, 첨부, 글꼴, 서식, 스크립트, 매크로, 문서 구조, 기타 분류. 가운데에는
이미지·영상·오디오·첨부·글꼴·스크립트 예시 카드. 오른쪽에는 선택한 이미지 미리보기와
파일명·경로·크기·해상도·형식·색상 모드·사용 위치. 화면의 숫자와 파일명은 설명용
예시임을 전제로 한다. 하단에 "최대 100 MB"와 "고르면 바로 시작! 원본은 그대로!".
고양이는 돋보기로 선택한 카드를 확인한다.
```

## 5장 프롬프트

```text
공통 사양을 적용한다. 상단 왼쪽에 5/5, 큰 제목은 "필요한 리소스 저장!".
왼쪽 세 단계는 "1 카드 선택", "2 파일 저장", "3 전체 ZIP - 분류 폴더로 저장".
전체 ZIP에는 이미지, 첨부파일, 오디오, 글꼴, 문서구조 폴더가 보이게 한다.
오른쪽 큰 녹색 방패에는 "브라우저 메모리 처리", "외부 전송 없음",
"원본 변경 없음", "매크로 실행 안 함", "암호·DRM·손상 미지원"을 적는다.
매크로 문서 아이콘에는 자물쇠와 빨간 X를 붙여 실행하지 않음을 명확히 한다.
고양이는 체크리스트를 들고 엄지를 올린다. 하단 말풍선은
"추출은 자동, 사용은 사람 확인!". 안전을 공식 인증하는 표현은 사용하지 않는다.
```

## 후처리 사양

- 각 이미지 생성 결과를 최종 `1536 × 1536` PNG로 맞춤
- 생성된 그림의 비율을 찌그러뜨리지 않음
- 부족한 가장자리만 배경색으로 기계적 패딩
- 패딩 과정에서 새 삽화·로고·문구를 추가하지 않음
- 파일명: `series5-comic-01.png`부터 `series5-comic-05.png`
- 게시 전 한글·숫자·파일명·단계 순서와 가장자리 잘림을 사람이 확인
