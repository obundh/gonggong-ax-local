# 시리즈 5 만화 이미지 제작 이력

## 대상 파일

- `series5-comic-01.png`
- `series5-comic-02.png`
- `series5-comic-03.png`
- `series5-comic-04.png`
- `series5-comic-05.png`

## 제작 과정

1. 사용자가 제공한 안내 만화 이미지를 색감·레이아웃·캐릭터 분위기의 스타일 참고
   자료로 확인했습니다.
2. 시리즈 5의 실제 기능, 릴리스 다운로드 순서, 실행 방식, 제한사항을 장별 정보
   구조로 정리했습니다.
3. OpenAI의 `imagegen`을 사용해 다섯 장을 새로 생성했습니다.
4. 결과물의 비율은 늘이거나 줄이지 않고, 가장자리의 빈 영역에 배경색을 더하는
   기계적 패딩으로 각 파일을 `1536 × 1536` 정사각형 PNG로 맞췄습니다.
5. 최종 파일을 장별 번호에 맞춰 저장했습니다.

사용자가 제공한 참고 이미지는 저장소의 배포 자산으로 복사하지 않았습니다. 참고
이미지의 구체적인 등장 장면을 복제하기보다 따뜻한 아이보리 배경, 굵은 검정·빨강
제목, 단계 카드, 빨간 스카프 고양이라는 전체적인 안내 만화 방향을 참고했습니다.

## 외부 자산과 표장

- 외부 스톡 이미지, 아이콘 묶음, 사진, 글꼴 파일을 의도적으로 삽입하지 않았습니다.
- 외부 회사·기관의 공식 로고를 생성하도록 요청하지 않았습니다.
- 2장의 `GitHub`와 `Releases` 표기는 사용자가 찾아가야 할 서비스와 메뉴를 설명하는
  텍스트입니다. 화면은 이해를 위한 생성형 도식이며 GitHub의 실제 화면 캡처가 아닙니다.
- 생성 모델이 만든 단순한 아이콘이나 UI 모양이 기존 표장과 우연히 비슷해 보일 수
  있으므로, 외부 공개 전 사람이 최종 이미지를 다시 확인해야 합니다.
- 이 만화는 GitHub, Microsoft, 한글과컴퓨터 또는 문서 형식 권리자의 제작·보증·후원을
  뜻하지 않습니다.

## 생성 결과의 한계

- 생성형 이미지의 한글과 UI는 실제 프로그램 화면과 완전히 같지 않을 수 있습니다.
- 4장의 파일명과 리소스 개수는 설명용 예시이며 성능 측정 결과가 아닙니다.
- 5장의 방패는 제품 인증 마크가 아니라 처리 원칙을 요약한 자체 설명 도형입니다.
- `외부 전송 없음`은 현재 시리즈 5의 문서 처리 경로를 설명합니다. 사용자의 운영체제,
  브라우저 확장 기능, 보안 프로그램, 동기화 폴더 등 PC 전체의 통신을 보증하는 표현은
  아닙니다.
- 이미지보다 [초보자 설명서](../../../docs/SERIES5_BEGINNER_GUIDE.md)의 최신 문구를
  우선합니다.

## 재생성 정보

재생성 시 사용할 공통 지시, 장별 문구, 금지 요소와 패딩 사양은
[PROMPTS.md](PROMPTS.md)에 기록했습니다. 이미지 생성 후에는 한글, 파일명,
버전, 지원 형식 수, 100 MB 제한, 매크로 미실행 안내를 다시 검수해야 합니다.
