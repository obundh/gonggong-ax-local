공공 AX 로컬 시리즈 5 - 문서 리소스 추출기
Windows x64 포터블판 처음 사용 설명서
============================================================

[무엇을 하는 프로그램인가요?]

문서 파일 안에 들어 있는 이미지, 영상, 오디오, 첨부 파일, 글꼴,
서식, 스크립트·매크로, 문서 구조 파일을 찾아 분류하고 꺼내 줍니다.
문서는 외부 서버로 전송하지 않고 이 PC 안에서 처리합니다.


[1. GitHub에서 다운로드하기]

1) 안내받은 GitHub 저장소의 Releases 페이지를 엽니다.
2) "공공 AX 로컬 시리즈 5" 또는 "series5-v{{VERSION}}" 릴리스를 엽니다.
3) Assets가 접혀 있으면 Assets를 누릅니다.
4) 아래 이름의 ZIP 파일을 누릅니다.

   GonggongAX-Series5-Resource-Extractor-{{VERSION}}-win-x64.zip

5) 브라우저가 다운로드 여부를 물으면 저장 또는 다운로드 유지를 선택합니다.
   공식 GitHub Releases 주소와 파일명이 맞는지 먼저 확인하세요.


[2. ZIP 압축 풀기]

1) 파일 탐색기에서 다운로드 폴더를 엽니다.
2) 내려받은 ZIP 파일을 마우스 오른쪽 버튼으로 누릅니다.
3) "모두 압축 풀기"를 누릅니다.
4) 원하는 폴더를 선택한 뒤 "압축 풀기"를 누릅니다.

중요: ZIP 파일 안에서 프로그램을 바로 실행하지 마세요.
EXE, CMD, 설명서가 모두 같은 폴더에 있어야 합니다.


[3. 딸깍 한 번으로 실행하기]

압축을 푼 폴더에서 아래 파일을 더블클릭합니다.

   시리즈5_실행.cmd

설치 과정은 없습니다. 잠시 뒤 "문서 리소스 추출기" 창이 열립니다.
다음부터도 같은 CMD 파일을 더블클릭하면 됩니다.


[4. Windows 보호 경고가 나올 때]

이 포터블판은 현재 코드 서명되지 않았습니다. 그래서 Windows에서
"Windows의 PC 보호" 또는 "알 수 없는 게시자" 경고가 표시될 수 있습니다.

계속하기 전 반드시 다음을 확인하세요.

- GitHub 공식 Releases에서 직접 내려받았는지
- 파일명이 안내된 이름과 같은지
- 아래 [파일 무결성 확인]의 SHA-256 값이 일치하는지

확인을 마친 뒤 Windows SmartScreen 화면에서 "추가 정보"를 누르고
"실행"을 선택합니다. 출처나 해시가 다르면 실행하지 말고 삭제하세요.


[5. 문서에서 리소스 꺼내기]

1) "파일 선택"을 누르거나 문서를 점선 상자에 끌어 놓습니다.
2) 분석이 끝나면 왼쪽 분류 목록에서 원하는 종류를 선택합니다.
3) 가운데 목록에서 파일을 눌러 이름, 형식, 크기, 사용 위치를 확인합니다.
4) "선택 다운로드"로 한 파일을 저장하거나
   "전체 ZIP 다운로드"로 모든 리소스를 한 번에 저장합니다.

매크로와 스크립트는 실행하지 않으며 별도 분류로만 표시합니다.


[지원 문서]

- 한글: HWPX
- Word: DOCX, DOCM, DOTX, DOTM
- PowerPoint: PPTX, PPTM, POTX, POTM, PPSX, PPSM
- Excel: XLSX, XLSM, XLSB, XLTX, XLTM
- OpenDocument: ODT, ODS, ODP, ODG, OTT, OTS, OTP, OTG
- Visio: VSDX, VSDM, VSSX, VSSM, VSTX, VSTM
- XPS: XPS, OXPS
- 전자책: EPUB

지원하지 않음: HWP, DOC, PPT, XLS 같은 구형 바이너리 문서,
PDF, 일반 ZIP, 암호화·DRM·손상 문서


[파일 무결성 확인]

ZIP과 함께 제공되는 .sha256 파일은 다운로드한 ZIP 자체를 확인합니다.
압축을 푼 뒤 SHA256SUMS.txt는 폴더 안 개별 파일을 확인합니다.

초보자용 확인 방법:

1) 다운로드 폴더의 빈 곳을 Shift 키를 누른 채 마우스 오른쪽 버튼으로
   누르고 "터미널에서 열기"를 선택합니다.
2) 아래 명령을 입력합니다. 파일명은 실제 버전에 맞게 바꿉니다.

   Get-FileHash .\GonggongAX-Series5-Resource-Extractor-{{VERSION}}-win-x64.zip -Algorithm SHA256

3) 표시된 Hash 값이 .sha256 파일의 값과 완전히 같은지 비교합니다.
   한 글자라도 다르면 실행하지 마세요.


[문제가 생길 때]

- CMD가 EXE를 찾지 못함
  ZIP 안의 일부 파일만 꺼낸 상태입니다. "모두 압축 풀기"를 다시 하세요.

- 창이 열리지 않음
  Windows x64 PC인지 확인하고, 보안 프로그램의 차단 기록을 확인하세요.

- 문서가 열리지 않음
  지원 확장자인지 확인하세요. 암호, DRM, 파일 손상도 확인하세요.

- 이미지 미리보기가 안 됨
  추출은 가능하지만 브라우저가 바로 표시하지 못하는 이미지 형식일 수 있습니다.
  해당 리소스를 다운로드해 전용 프로그램에서 여세요.

- 원본 문서가 바뀔까 걱정됨
  원본 파일을 수정하지 않습니다. 리소스를 읽어 새 파일로 저장합니다.


[안전하게 사용하기]

- 중요한 문서는 사본으로 먼저 시험하세요.
- 추출된 매크로, 스크립트, 실행 파일은 출처를 확인하기 전 열지 마세요.
- 분석 결과는 문서 내부 패키지 구조를 기준으로 합니다.
- 프로그램을 종료하면 함께 시작된 PC 내부 화면 서버도 종료됩니다.
