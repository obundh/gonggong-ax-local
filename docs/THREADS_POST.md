# Threads 게시용 문안

## 본문

사건명: 100쪽짜리 공공 가이드에서 숨어 있는 오류 찾기.

문서 수사대 애기 고양이가 문제부터 분석했습니다.
분량이 너무 많고, 오류 위치를 모르고, 문제 종류도 제각각입니다.

그래서 HWP·HWPX·DOCX·TXT를 PC 밖으로 보내지 않고 검사하는
`공공AX 로컬 시리즈 2 - 문서 검수`를 만들었습니다.

`할수`는 띄어쓰기, `않됩니다`는 맞춤법, `금일`은 공공언어처럼
문제 종류를 나눠서 보여줍니다. 맞춤법만 보고 싶으면 `맞춤법`만 누르면 됩니다.
원문 형광펜과 오른쪽 검사 결과가 같이 좁혀지고, 전후 비교도 할 수 있습니다.

기계적으로 확실한 오류는 빠르게 고치되, 문맥 판단은 사람이 마지막으로 확인합니다.
원본 파일은 바꾸지 않고 수정본 TXT와 검사보고서 CSV를 내려받습니다.

Windows 포터블 EXE 하나로 실행합니다.
