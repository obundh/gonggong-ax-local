# 공공AX 로컬 시리즈 5 초보자 설명서

문서 리소스 추출기는 HWPX·DOCX·PPTX 같은 ZIP 패키지 문서를 열어 그 안의
이미지, 영상, 오디오, 첨부파일, 글꼴, 서식, 스크립트·매크로, 문서 구조를
분류하고 저장하는 Windows x64용 포터블 도구입니다.

설치 프로그램과 Node.js가 필요하지 않습니다. 공식 실행용 ZIP을 한 번 내려받아
압축을 푼 뒤 `시리즈5_실행.cmd`를 더블클릭하면 됩니다.

## 1. 준비물

- Windows 10 또는 Windows 11이 설치된 x64 PC
- 인터넷 연결: GitHub에서 프로그램을 받을 때만 필요
- 추출할 지원 문서: 한 파일당 최대 100 MB
- 결과를 저장할 여유 공간

프로그램을 받은 뒤 문서를 분석할 때는 인터넷 연결이 필요하지 않습니다. 현재
시리즈 5는 선택한 문서를 PC의 로컬 브라우저 메모리에서 분석하도록 구현되어
있으며, 문서를 외부 파일 업로드 API로 보내는 기능은 없습니다. 조직의 보안
정책이나 문서 반출 규정은 별도로 확인하세요.

## 3. 다운로드 위치

브라우저의 기본 저장 위치는 보통 Windows의 `다운로드` 폴더입니다.

- Edge·Chrome: 오른쪽 위 다운로드 아이콘 또는 `Ctrl` + `J`
- Firefox: 오른쪽 위 다운로드 화살표 또는 `Ctrl` + `J`
- 파일 탐색기: 왼쪽의 `다운로드`

다운로드 목록에서 폴더 아이콘이나 `폴더에서 보기`를 누르면 파일이 있는 위치가
바로 열립니다. 파일명이 정확한지 확인하세요. 이름 끝에 `(1)`이 붙은 파일은 같은
파일을 다시 받은 것일 수 있습니다.

## 4. SHA-256 확인

SHA-256은 내려받은 ZIP이 릴리스에 올린 파일과 같은지 확인하는 지문입니다.
게시된 값과 실제 값이 한 글자라도 다르면 실행하지 말고 파일을 삭제한 뒤 공식
릴리스에서 다시 받으세요.

### PowerShell 자동 비교

1. ZIP과 `.zip.sha256` 파일을 같은 `다운로드` 폴더에 둡니다.
2. 시작 메뉴에서 `PowerShell`을 검색해 엽니다.
3. 아래 명령을 한 줄씩 붙여 넣습니다.

```powershell
Set-Location "$env:USERPROFILE\Downloads"
$zip = "GonggongAX-Series5-Resource-Extractor-0.1.0-win-x64.zip"
$expected = ((Get-Content ".\$zip.sha256").Trim() -split '\s+')[0]
$actual = (Get-FileHash ".\$zip" -Algorithm SHA256).Hash
$actual
$expected
$actual -ieq $expected
```

마지막 결과가 `True`이면 두 값이 같습니다. `False`, 빨간 오류, 빈 값이 나오면
실행하지 마세요. 브라우저가 다른 폴더에 저장했다면 먼저 그 폴더로 이동하거나
아래의 파일 탐색기 방식을 사용합니다.

### 파일 탐색기 중심 확인

Windows의 기본 `속성` 창은 SHA-256을 표시하지 않습니다. 다음 방식은 경로를
직접 입력하지 않아도 됩니다.

1. 파일 탐색기에서 ZIP을 `Shift` 키를 누른 채 마우스 오른쪽 버튼으로 누릅니다.
2. `경로로 복사`를 누릅니다.
3. 시작 메뉴에서 `PowerShell`을 엽니다.
4. `Get-FileHash `를 입력하고, 뒤에 복사한 경로를 붙인 뒤
   ` -Algorithm SHA256`을 입력합니다.

예시:

```powershell
Get-FileHash "C:\Users\사용자\Downloads\GonggongAX-Series5-Resource-Extractor-0.1.0-win-x64.zip" -Algorithm SHA256
```

표시된 `Hash`를 릴리스 페이지 또는 함께 받은 `.zip.sha256` 파일의 64자리 값과
비교합니다. 온라인 해시 계산 사이트에 파일을 올리는 방식은 사용하지 마세요.

## 5. ZIP 압축 풀기

1. `다운로드` 폴더에서 실행용 ZIP을 마우스 오른쪽 버튼으로 누릅니다.
2. `모두 압축 풀기`를 누릅니다.
3. 압축을 풀 위치를 선택합니다. 처음에는 기본으로 제시되는 폴더를 사용해도 됩니다.
4. `압축 풀기`를 누릅니다.
5. 새 폴더 안에 다음 파일이 함께 있는지 확인합니다.

   - `시리즈5_실행.cmd`
   - `GonggongAX-Series5-Resource-Extractor-0.1.0-win-x64.exe`
   - `처음_사용_설명서.txt`
   - `SHA256SUMS.txt`
   - `LICENSE`
   - `THIRD_PARTY_NOTICES.md`

ZIP 미리보기 창 안에서 `시리즈5_실행.cmd`만 바로 실행하면 EXE를 찾지 못할 수
있습니다. 반드시 `모두 압축 풀기`를 먼저 하고, 폴더 안 파일을 따로 옮기지 마세요.

## 6. 원클릭 실행

1. 압축을 푼 폴더에서 `시리즈5_실행.cmd`를 찾습니다.
2. 파일을 더블클릭합니다.
3. 잠시 기다리면 `공공 AX 로컬 시리즈 5 - 문서 리소스 추출기` 전용 창이 열립니다.

설치 마법사나 별도 서버 설정은 없습니다. 다음부터는 같은
`시리즈5_실행.cmd`를 다시 더블클릭하면 됩니다. CMD가 같은 폴더의 시리즈 5
실행파일을 찾아 시작하므로 두 파일의 이름을 바꾸거나 서로 다른 폴더로 옮기지
마세요.

### SmartScreen 경고

현재 포터블 실행파일은 코드 서명되지 않았습니다. Windows가 `Windows의 PC
보호`, `알 수 없는 게시자` 등의 경고를 표시할 수 있습니다. 경고가 떴다는 이유만으로
무조건 우회하지 마세요.

계속하기 전에 다음 세 가지를 모두 확인합니다.

1. 주소 표시줄이 `github.com/obundh/gonggong-ax-local-2`인지
2. 공식 `series5-v0.1.0` 릴리스의 실행용 ZIP을 받았는지
3. SHA-256 값이 릴리스의 값과 정확히 같은지

세 항목이 모두 맞고 조직 정책상 실행이 허용된 경우에만 SmartScreen의 `추가 정보`를
눌러 표시된 파일명을 다시 확인한 뒤 실행 여부를 결정하세요. 출처나 해시가 다르거나
확신이 없으면 실행하지 말고 담당자에게 문의하세요. 회사·기관 PC에서 실행이 정책으로
차단된 경우 보안 설정을 임의로 변경하지 말고 관리자에게 승인 절차를 요청하세요.

## 7. 문서 분석

1. 시작 화면의 `파일 선택`을 누르거나 문서를 점선 영역에 끌어놓습니다.
2. 분석이 끝날 때까지 기다립니다. 큰 문서는 시간이 더 걸릴 수 있습니다.
3. 왼쪽 분류에서 이미지·영상·오디오 등 원하는 종류를 고릅니다.
4. 가운데 리소스 카드에서 파일명, 경로, 형식, 크기, 문서 내 사용 위치를 확인합니다.
5. 미리보기를 지원하는 리소스는 오른쪽에서 내용을 확인합니다.

분류 항목은 이미지, 영상, 오디오, 첨부파일, 글꼴, 서식, 스크립트·매크로,
문서 구조, 기타입니다. 문서 패키지의 관계 정보를 바탕으로 슬라이드·시트·페이지 등
사용 위치를 찾지만, 모든 문서에서 사람이 보는 화면과 완전히 같은 의미를 복원하는
기능은 아닙니다.

원본 문서는 읽기만 하며 덮어쓰지 않습니다. 중요한 문서는 사본으로 먼저 시험하는
것을 권장합니다.

## 8. 리소스 저장

### 개별 저장

1. 필요한 리소스 카드를 선택합니다.
2. 카드 또는 미리보기 영역의 파일 저장 버튼을 누릅니다.
3. 브라우저가 묻는 위치에 파일을 저장합니다.

### 전체 ZIP 저장

1. 분석 결과의 `전체 ZIP`을 누릅니다.
2. 분류별 폴더가 들어 있는 새 ZIP을 원하는 위치에 저장합니다.
3. 저장한 ZIP을 풀어 필요한 리소스를 확인합니다.

추출된 파일은 원본 문서에 포함된 데이터입니다. 특히 스크립트·매크로·실행파일은
프로그램이 실행하지 않고 별도 분류만 합니다. 출처와 용도를 확인하기 전에는 추출된
파일을 실행하거나 다른 프로그램에서 활성화하지 마세요.

형식으로 바꾼 일반 ZIP은 문서로 처리하지 않습니다.

## 10. 미지원 범위

- 구형 바이너리 문서: `.hwp`, `.doc`, `.ppt`, `.xls`, `.vsd`
- PDF: `.pdf`
- 일반 압축파일: `.zip`
- 암호가 설정되었거나 DRM으로 보호된 문서
- 내부 패키지가 손상되었거나 확장자와 실제 형식이 다른 문서
- 100 MB를 초과하는 파일

PDF나 구형 문서는 단순히 ZIP을 푸는 것과 구조가 달라 별도 분석 엔진이 필요합니다.
암호나 DRM을 해제하는 기능은 제공하지 않습니다.

## 11. 종료와 삭제

### 종료

전용 창 오른쪽 위 `X`를 눌러 닫습니다. 함께 시작된 로컬 앱 프로세스도 종료됩니다.
작업 중 저장하지 않은 추출 결과는 창을 닫으면 다시 문서를 선택해 만들어야 합니다.

### 삭제

이 버전은 포터블판이므로 Windows 앱 제거 메뉴를 사용할 필요가 없습니다.

1. 시리즈 5 창을 닫습니다.
2. 압축을 풀었던 시리즈 5 폴더 전체를 휴지통으로 보냅니다.
3. 필요하면 `다운로드` 폴더의 원본 ZIP과 `.sha256` 파일도 삭제합니다.

프로그램에서 따로 저장한 리소스와 전체 ZIP은 다른 폴더에 있으므로 자동으로 삭제되지
않습니다. 필요 여부를 확인한 뒤 별도로 정리하세요.

## 12. 문제 해결

### `실행파일을 찾을 수 없습니다`

ZIP 안에서 CMD만 실행했거나 일부 파일만 꺼낸 상태입니다. 원본 ZIP을 마우스 오른쪽
버튼으로 눌러 `모두 압축 풀기`를 다시 하고, CMD와 EXE가 같은 폴더에 있는지
확인합니다.

### 창이 열리지 않음

- Windows x64 PC인지 확인합니다.
- 공식 릴리스와 SHA-256을 다시 확인합니다.
- 작업 표시줄에 창이 숨어 있지 않은지 확인합니다.
- 회사·기관 보안 프로그램의 차단 기록은 담당자와 함께 확인합니다.
- 파일명이나 폴더 구조를 바꿨다면 새로 압축을 풀어 다시 실행합니다.

### 문서 선택 불가

지원 확장자 33종에 포함되는지, 파일이 100 MB 이하인지 확인합니다. `.hwp`, `.doc`,
`.ppt`, `.xls`, `.pdf`, 일반 `.zip`은 선택 대상이 아닙니다.

### `형식 불일치` 또는 `손상` 오류

확장자만 바꾼 파일이거나 문서 저장 중 패키지가 손상되었을 수 있습니다. 원래 작성
프로그램에서 문서를 연 뒤 새 파일로 다시 저장하고 시험합니다. 중요한 원본은 별도로
보관하세요.

### 암호·DRM 오류

시리즈 5는 암호나 DRM을 우회하지 않습니다. 권한이 있는 작성 프로그램에서 보호되지
않은 사본을 만들 수 있는지 문서 담당자에게 확인하세요.

### 미리보기 없음

리소스가 추출되어도 브라우저가 해당 형식을 바로 표시하지 못할 수 있습니다. 개별
파일로 저장한 뒤 그 형식을 지원하는 신뢰할 수 있는 프로그램에서 확인합니다.

### 저장 버튼 반응 없음

브라우저의 다운로드 차단 표시를 확인하고, 저장 공간이 충분한지 확인합니다. 전체
ZIP이 크면 생성과 저장에 시간이 걸릴 수 있습니다.

## 13. 개발자 빌드

일반 사용자는 이 절을 수행할 필요가 없습니다. 개발자는 Windows x64와 Node.js
22.13 이상에서 저장소를 받은 뒤 다음 순서로 검증 및 패키징합니다.

```powershell
npm ci
npm run lint
npm test
npm run desktop:series5
```

완료되면 다음 두 파일이 생성됩니다.

```text
release/GonggongAX-Series5-Resource-Extractor-0.1.0-win-x64.zip
release/GonggongAX-Series5-Resource-Extractor-0.1.0-win-x64.zip.sha256
```

`npm run desktop:series5`는 시리즈 5 시작 경로를 검사하는 패키지 스모크 테스트,
실행용 ZIP 구성 확인, ZIP용 SHA-256 생성까지 수행합니다. 개발 화면만 확인하려면
다음 명령을 실행한 뒤 `http://localhost:3000/series5`를 엽니다.

```powershell
npm run dev
```

## 14. 이용 전 확인

- 추출 결과는 문서 내부 패키지 구조를 기준으로 한 자료 목록입니다.
- 추출된 리소스의 저작권·개인정보·재사용 권한은 사용자가 확인해야 합니다.
- 매크로와 스크립트를 실행하지 않는 것과 파일 자체가 안전하다는 것은 다른 의미입니다.
- 중요한 업무 문서는 사본으로 시험하고, 저장 결과를 사람이 최종 확인하세요.
