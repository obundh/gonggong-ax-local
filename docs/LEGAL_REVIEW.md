## 의존성 보안 점검

2026-07-26 기준 `npm audit --omit=dev`는 프로덕션 의존성 취약점 0건입니다.
Next.js, React, React DOM, React Server DOM, PostCSS, Sharp는 감사 결과에 맞춰
수정판으로 올렸고 전체 빌드·테스트를 다시 수행했습니다.

전체 개발 의존성 감사에는 30건(낮음 1, 보통 4, 높음 25)이 남습니다. 주요
경로는 린터, Drizzle 개발 도구, Electron 패키징 도구의 전이 의존성입니다.
이 `node_modules`는 포터블 EXE에 포함하지 않지만 빌드 공급망에는 영향을 줄 수
있습니다. 현재 최신 `electron-builder`도 관련 경고를 포함하고, 감사 도구가
제안하는 일부 “수정”은 구버전으로의 주요 변경이므로 자동 적용하지 않았습니다.
릴리스는 깨끗한 설치 환경에서 만들고 해시를 제공하며, 후속 버전에서 도구 공급자가
수정판을 내면 갱신해야 합니다.

## 공공데이터 출처표시

`data/public-language.json`은 공공데이터포털의
“문화체육관광부 국립국어원_쉽고 바른 공공언어 쓰기 평가용 용어 목록”을
검사 규칙에 맞게 변환한 스냅샷입니다.

- 제공기관: 국립국어원
- 원문: <https://www.data.go.kr/data/15130006/fileData.do>
- 이용조건: 공공누리 제1유형(출처표시)
- 변환 내용: 용어, 이표기·오표기, 대안어를 로컬 검색용 JSON으로 구조화

## 생성형 안내 이미지

`public/document-review-hero.png`와 `public/threads/source-*.png`는 OpenAI
이미지 생성 기능으로 이 프로젝트를 위해 새로 만들었습니다.
`public/threads/threads-*.jpg`는 생성 그림, 정확한 한국어 대사, 실제 구동 화면을
로컬에서 조합한 게시용 캐러셀입니다. OpenAI 이용약관은 OpenAI와 사용자
사이에서는, 관련 법이 허용하는 범위에서 출력의 권리를 사용자에게 귀속·양도한다고
설명합니다. 다만 생성 결과는 고유하지 않을 수 있고, 국가별로 순수 AI 생성물의
저작권 보호 여부가 달라질 수 있습니다. 이미지에는 식별 가능한 외부 로고·상표·
워터마크를 넣지 않았습니다.

실제 화면 캡처에는 프로젝트에 내장된 예시 문서만 사용했으며 개인정보나 기관
비공개 문서를 포함하지 않습니다.

- OpenAI 이용약관: <https://openai.com/policies/terms-of-use/>

## 개인정보·기밀문서

시리즈 2는 문서 내용을 PC 안에서 처리하며 외부 파일 업로드 API를 사용하지
않습니다. 다만 운영체제 백업, 악성코드, 화면 캡처, 공유 폴더 등 프로그램 밖의
위험까지 제거하지는 않습니다. 기관의 비밀·개인정보 처리 규정과 승인된 PC 사용
정책을 따라야 합니다.
